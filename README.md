# Карточка — AI-генератор товарных карточек

Загружаешь фото товара, настраиваешь сцену (тон, фон, свет, композицию) —
Gemini 2.5 Flash Image («Nano Banana») перерисовывает окружение, сохраняя
сам товар без изменений. Заголовок, цена и бейдж накладываются поверх
точным слоем текста.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка для продакшена

```bash
npm run build
```

Готовый сайт появится в папке `dist/`.

## Деплой

Проще всего — **Vercel** или **Netlify**, оба бесплатны для таких проектов
и сами собирают сайт при каждом пуше в GitHub:

### Vercel
1. Залей этот проект в репозиторий на GitHub
2. На vercel.com → **Add New Project** → выбери репозиторий
3. Framework Preset определится сам как **Vite** — просто нажми **Deploy**

### Netlify
1. Залей проект в GitHub
2. На netlify.com → **Add new site** → **Import an existing project**
3. Build command: `npm run build`, Publish directory: `dist`

## API-ключ Gemini

Ключ вводится пользователем прямо в интерфейсе сайта (поле в первом блоке
настроек) и хранится только в `localStorage` его браузера — на сервер
проекта он не попадает и в код не зашивается.

Получить ключ: https://aistudio.google.com/apikey

**Не публикуй свой ключ** в коде и не коммить его в репозиторий — он
привязан к твоему аккаунту Google и биллингу.
